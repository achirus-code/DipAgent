# DipAgent add-on

The add-on runs the DipAgent agent: a small service that checks the market around the clock, runs your bots and
places orders on Revolut X. It is controlled from the DipAgent **macOS menu bar app** – the add-on itself has no web
UI, only the REST API the app talks to (port 3470).

## Installation

1. **Settings → Add-ons → Add-on store → ⋮ → Repositories**, add `https://github.com/achirus-code/DipAgent`.
2. Install **DipAgent** and open its **Configuration** tab.
3. Optionally set an **API token** (e.g. `openssl rand -hex 24`). If you leave it empty, the agent generates one on
   the first start and prints it to the add-on **Log**.
4. **Start** the add-on. The state switches to *Started* once the API answers.
5. Build and install the macOS app (see the project README), open **Settings**, enter the Home Assistant host
   (IP or host name – port 3470 is added automatically) and the API token, then **Connect**.
6. Connect Revolut X from the app: **Settings → Revolut X → Connect**. The key pair is generated by the agent and
   never leaves the add-on.

## Options

| Option | Default | Description |
|---|---|---|
| `api_token` | generated | Token the macOS app authenticates with. |
| `exchange` | `revolutx` | `revolutx` = real exchange, `mock` = simulated market for trying things out. |
| `tick_seconds` | `30` | How often the bots check the market. |
| `taker_fee` | `0.0009` | Fee used for simulated (paper) trades. |
| `mock_speed` | `1` | Only for `exchange: mock` – time lapse (60 = one market hour per minute). |

Live trading, risk limits and bots are managed in the app and stored in the add-on data, not in the options.
The time zone for the "today" P&L summary follows your Home Assistant time zone.

## Data, backups and updates

- All data (SQLite database, API token, Revolut X key) lives in the add-on's `/data` directory and is included in
  Home Assistant backups. The add-on is stopped for the few seconds of a backup so the database is copied
  consistently; bots pick up where they left off.
- **Moving from Docker to the add-on:** in the app, connected to the old agent, use *Settings → Backup → Export*,
  then connect to the add-on and *Import* the file. Live trading is off after the import until you enable it again.
- Updates appear in the add-on store like for any other add-on. Only one instance may run per data directory.

## Network

The app talks plain HTTP with a bearer token. Keep port 3470 inside your home network or reach it via a VPN – don't
expose it to the internet. Revolut X API keys can additionally be restricted to the add-on's public IP, which the
app shows during the setup.

## Trying it without Revolut X

Set `exchange` to `mock` (and e.g. `mock_speed` to `60`): the agent then simulates a market with realistic ups and
downs.
